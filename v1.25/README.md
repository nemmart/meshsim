# mesh-sorter v1.1 (spec through part M, 2026-10-27; the milestone merge of the spec, simulator and replayer sessions)

A 64-tile mesh sorter: the hardware specification, its figures, a cycle-level simulator, the tile software (including a complete parallel sort), and the measurement kits.

**Start here:** `Intro.pdf` for the ideas, then `Reference.pdf` to program the machine; then `spec/machine-spec.md` for the hardware, with `diagrams/` beside it; `sw/REGISTERS.md`, `sw/CONVENTIONS.md` and `sw/RECIPES.md` to program a tile; `meshsim/README.md` to run the simulator (`meshsim/run_tests.sh`); `kit/README.md` to measure the sort.

**Not rebuilt in this session:** `Intro.pdf`, `Reference.pdf` and the figures (they predate spec 26n; `make_docs.sh` rebuilds them).

**In brief:** on meshsim v1.1 (spec 26n), the sort orders 64 × 65,536 records (32-bit keys with 32- or 128-bit values) in about 0.9–1.4M cycles on uniform keys and up to about 2.0M on the most skewed data sets tested (`RESULTS-full-size.md`; v1.0's figures, 0.9–1.5M and 2.2M, are in `results/full-size/`). The spec's open items (section 13) are the questions left for the hardware.

**Planning notes:** `planning/PLANNING-NOTES-2026-10-27.md` collects this revision's status, measurements, rulings, the chip-level design not yet in the spec, open design discussions and the to-do list for the next revision.
