# Building

Everything generated in this release is generated from sources in it. This page lists what builds what, and what each needs.

## Documents and figures

Every figure is drawn by a Python script; nothing is hand-drawn. One command rebuilds them all:

```
./make_docs.sh
```

| what | built by | output | needs |
|---|---|---|---|
| the figure set (29 figures) | `diagrams/src/build.sh` (one script per figure, sharing `common.py` and `rtl.py`) | `diagrams/svg/`, `diagrams/png/` | Python 3; cairosvg for the PNGs |
| the register reference | `sw/regdoc/src/build_pdf.sh` (from `sw/REGISTERS.md`; its five example diagrams import `diagrams/src/common.py`) | `Reference.pdf`, `sw/regdoc/svg/`, `sw/regdoc/png/` | Python 3, cairosvg, WeasyPrint, pandoc |
| the introduction | `intro/src/build.sh` (from `intro/src/Intro.md`; its figures draw from one toy model, `toy.py`) | `Intro.pdf`, `intro/svg/`, `intro/png/` | Python 3, cairosvg, WeasyPrint, pandoc |

`pip install cairosvg weasyprint` and your system's `pandoc` cover all three. The SVGs are the masters; the PNGs are renderings at twice the size, for slides and viewers without SVG.

Two documents are partly generated from the simulator and checked by its tests:
- `sw/mesh.h` is generated by `meshsim/src/Registers.java` (`java -cp build Registers sw/mesh.h` in `meshsim/`);
- `sw/REGISTERS.md`'s tables (between its `generated` markers) by `meshsim/src/RegDoc.java` (`java -cp build RegDoc`); RegDocTest fails if they, `mesh.h` and the simulator disagree;
- `sw/RECIPES.md`'s code blocks are the marked regions of `meshsim/sw/tests/rcp_*.c`; RecipeTest fails if they differ.

## The simulator and the tile software

See `meshsim/README.md`. In short: Java 17 or later for the simulator; `riscv64-unknown-elf-gcc` (with picolibc) for the tile programs, the sort, the split and the planner. `meshsim/run_tests.sh` checks the layout, builds the tile software, compiles everything and runs every suite (`quick` skips the long runs).

## The kits

`kit/` (the measurement kit) and `verify-v1.0/` (the verification kit) are prebuilt and need only Java 17 or later: see their READMEs. `meshsim/kit/assemble.sh` rebuilds the measurement kit from the tree.
